Or let the installer do it

One command installs the core, the app, or both, checks each download against SHA256SUMS.txt, and updates whatever you already have when you run it again.

macOS, Linux, Raspberry Pi

curl -fsSL {{RAW_URL}}/tools/install.sh | sh

Windows (PowerShell)

irm {{RAW_URL}}/tools/install.ps1 | iex

Options (--what, --channel nightly, --dry-run) and where each thing is installed are on the home page. Package-manager manifests (Homebrew, winget, Scoop, Flatpak) are rendered by CI as templates in app/packaging/manifests; none is submitted yet.

Signing and verification

The macOS app is signed with a Developer ID and notarized in CI, so it opens without a Gatekeeper prompt. The Windows installer is not yet code-signed, so SmartScreen may warn. The core files are plain libraries and are not signed on any platform. To check a download, compare its SHA-256 with the line for it in the release's SHA256SUMS.txt: shasum -a 256 <file> on macOS and Linux, Get-FileHash <file> in PowerShell. Details: app/packaging/README.md.
