Install on macOS with Homebrew

The project tap installs the stable standalone app on Apple Silicon and Intel Macs.

brew tap Provenance-Emu/virtualjaguar
brew trust --cask Provenance-Emu/virtualjaguar/virtualjaguar
brew install --cask Provenance-Emu/virtualjaguar/virtualjaguar

For nightly builds, use the nightly macOS ZIP or the installer script with --what app --channel nightly.
