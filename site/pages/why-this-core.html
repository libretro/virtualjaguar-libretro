WhatBacked by

Old savestates keep loading. Every format any released core wrote can still be read (a CD state is refused on a different disc). savestate-compat.md · v3.1.0 notes

Enhancements built into the core

True-colour Gouraud shading and internal-resolution supersampling are options of the core itself, not a filter applied to the finished frame. Both shipped in v3.2.0 and v3.3.0, with the A/B captures and the settings that produced them on that page.

Found something broken

Check known problems first. Then use Discussions for reports and Issues for confirmed bugs. Attach your frontend log: the crash watchdog writes the failure signature into it.
