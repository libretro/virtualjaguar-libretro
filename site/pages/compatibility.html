Compatibility

Numbers over adjectives. The tables below are generated at site build time by parsing the committed test documents in this repository — nothing on this page is typed in by hand.

How to read this page. Three honest states: verified the committed test log shows the title reaching the stated stage · known issue a committed doc records a failure · not yet verified nobody has recorded a result. "Verified" here means headlessly verified to boot into game code — it is a regression gate, not a completed-the-game certificate. Rows reflect the local test corpus at the build revision stamped in the matrix ({{COMPAT_BUILD_IDS}}), run on the maintainer's disc images; your dump may differ.
Looking for the manual, not the matrix? Core options, file extensions, controller tables and frontend feature support are documented on the official libretro documentation page for this core (docs.libretro.com) — the canonical reference manual, maintained in libretro/docs. Jump straight to the core options reference or the controller tables. No BIOS or system files are required — the boot ROM and both Jaguar CD BIOSes are embedded in the core; the optional external CD BIOS override is described in the README's BIOS section. libretro additionally hosts a community-maintained Atari Jaguar compatibility list: a separate document from the machine-generated boot matrix below, with different methodology and a different scope (cartridges included).

Parsed from docs/cd-boot-matrix.md, which is produced by the repeatable harness cd_boot_matrix.sh. Every title is exercised in both CD modes: HLE (high-level-emulated CD BIOS) and BIOS (the real CD BIOS driving emulated BUTCH/DSA/FIFO hardware). "Reaches game code" means the 68000 was observed executing game-owned code in RAM with a healthy, non-looping PC trace.

Watchdog notes are the runtime crash watchdog's signatures recorded during the run. A lone cd_seek_wedge or video_stall line alongside a passing PC trace is frequently benign — e.g. Myst fires it during the intro movie's ~6 s all-black pause while the movie plays from RAM. The matrix doc discusses each case; the stage column, not the watchdog column, is the regression gate.
