Compatibility

Most of the library boots and plays. This page lists what does not, what was fixed recently, and how much to trust the test data. Current as of v3.9.0 (2026-10-14). No BIOS files are required (README: BIOS).

How much to trust the matrices

The two tables below are a headless smoke test, generated from committed logs. Reaches game code means the 68K was executing game code when the run ended. It does not mean the game can be finished, and menus are not told apart from gameplay. A “video undetermined” badge means the headless video check was inconclusive, not that the title is broken.

  • The cartridge matrix runs the Fast blitter only, so it cannot see freezes that only the default Accurate blitter hits, like #800 (fixed in v3.7.1).
  • In the cartridge matrix, 14 real-BIOS rows read “BIOS reject”: alternate or bad dumps and BIOS-only demos that the boot ROM itself refuses, not regressions (v3.8.0 notes).
  • The matrices record a stage plus coarse video and audio flags, so they cannot see most rendering or audio changes. Both were last regenerated for v3.8.0.

Your game is not listed, or the list says it runs and it does not? Report it in Discussions with your frontend log. The crash watchdog writes its failure signature there. libretro also keeps a community compatibility list.
