Organize your collection, connect a controller, use save states, and customize
your setup with shaders, themes and optional RetroAchievements.

## About this software

Virtual Jaguar brings Atari Jaguar and Jaguar CD emulation to your desktop.
Browse a visual game library with artwork, favorites and recently played games,
or use the controller-friendly TV interface.

- Load cartridges, CD images, CHD files and multi-disc playlists.
- Save and resume with save states and per-game configuration.
- Remap your controller and use the on-screen Jaguar keypad.
- Customize the picture with shader presets and the interface with themes and fonts.
- Connect optional RetroAchievements and Discord Rich Presence.
- Use LAN link play for compatible Jaguar link-cable games.
- Explore Jaguar software with memory, CPU/GPU/DSP and graphics debugging tools.

You supply your own game files. No commercial games or BIOS files are included.
Compatibility and performance vary by game and computer. Optional online features,
including achievements and artwork downloads, use an internet connection.
RetroAchievements are separate from Steam Achievements.

The paid Steam edition supports continued development. Free desktop downloads
with the same core features and the project's source code remain available on
the project website.
