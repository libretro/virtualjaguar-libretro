Virtual Jaguar -- third-party components in the app packages
=============================================================

Virtual Jaguar itself is free software under the GNU General Public License
v3.0 (LICENSE.txt).  Source: https://github.com/libretro/virtualjaguar-libretro

Linked into the program (all compatible with the GPLv3):

  SDL3                 zlib license        https://libsdl.org
  Dear ImGui           MIT                 https://github.com/ocornut/imgui
  libchdr              BSD-3-Clause        https://github.com/rtissera/libchdr
    with LZMA SDK (public domain), miniz (MIT), Zstandard (BSD-3-Clause)

Linked in unless the build was made with -DVJ_APP_FREETYPE=OFF (the default is ON):

  FreeType             FreeType License (FTL), used under its terms; compatible with the GPLv3
                       (the GPLv2 option is not used).  https://freetype.org
                       Portions of this software are copyright (c) The FreeType Project
                       (www.freetype.org).  All rights reserved.

Shipped as separate files beside the program (not linked into it):

  librashader runtime  (librashader.dll / .dylib / .so, in the macOS, Windows, AppImage
                       and .deb packages)
                       Dual-licensed: MPL-2.0 OR GPL-3.0-only (librashader-capi's declared
                       licence; upstream ships both texts, LICENSE.md and LICENSE-GPL.md).
                       Loaded at run time when you turn shaders on.  The macOS (Intel and
                       Apple silicon) and Linux libraries in these packages were built,
                       unmodified, from the upstream source at tag librashader-v0.12.1
                       (commit 07ac790cdb9826f37cf8e1daf5011f03e3c4daa7) with
                       `cargo xtask build --profile optimized`; the recipe is
                       .github/workflows/librashader.yml and
                       app/packaging/librashader/ in the Virtual Jaguar repository.  The
                       Windows library is the unmodified upstream release binary of tag
                       librashader-v0.12.0.  Source: https://github.com/SnowflakePowered/librashader
                       (https://www.mozilla.org/MPL/2.0/ for the MPL-2.0 text).  You can
                       replace the file with your own build of the same library.
                       The library statically contains the Rust crates it depends on, each
                       under its own licence; they are listed in Cargo.lock at the tag above.

  shaders/slang-shaders/
                       An unmodified subset of https://github.com/libretro/slang-shaders.
                       There is no single licence: every shader states its own in its
                       header (GPL, MIT, public domain, ...) and the per-folder
                       LICENSE/README files are included.  See
                       shaders/slang-shaders/NOTICE-virtualjaguar.txt.

  cheats/              The Atari Jaguar cheat files of libretro-database, created by Gent
                       of Emucheats.  Creative Commons Attribution-ShareAlike 4.0
                       International; the licence text is cheats/LICENSE-libretro-database.txt.

  libretro-db/         The Atari Jaguar and Jaguar CD .dat files of libretro-database
                       (no-intro / redump metadata).  Creative Commons
                       Attribution-ShareAlike 4.0 International
                       (https://github.com/libretro/libretro-database).

Anything absent from your package (for example a build made with the bundling options
off) is simply not there; the program works without it.
