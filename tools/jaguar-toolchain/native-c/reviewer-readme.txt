Orbital QA
Virtual Jaguar App Review sample

1. Extract this ZIP. In Virtual Jaguar, choose File > Open and select
   orbital-qa.j64. Use the default cartridge boot setting. The title
   and animated starfield should appear automatically.

2. Press F3 to see your keyboard or controller mappings (Fn+F3 if
   your Mac uses the function keys for system shortcuts).

   In the demo                Default keyboard
   Steer with the D-pad       Arrow keys
   A: boost                   X
   B: change color            Z
   C: return to center        C
   Pause: freeze or resume    Right Shift or Backspace
   Option: change star speed  Return

3. To test a controller, connect a supported USB gamepad or pair
   a Bluetooth gamepad in macOS System Settings, then try the controls.
   The tiles at the bottom of the demo light up as you use them.

4. To test save states, choose Emulation > Save State, steer the ship
   away from its saved position, and choose Emulation > Load State.
   The ship should return to its saved position.

Orbital QA is an original, silent test cartridge. No account or separate
BIOS file is required to run it with default settings.
